## 2.2. Потоки

**Засветка слоя (шаг 1, без станка):**
```
gerber2ldi job <gbr> --profile P --side S --process C --power F --frame <контур> -o layer.nc
  source: слой гербера (gerbonara) → рамка, мм; контур → рамка платы
  raster: полосы по Y → строка растра на центре проезда → ScanRow (RLE)
  scan:   компенсация пятна (r из P) → перекос (θ из P) → зеркало (S = bottom, ось — рамки) → полярность (из C)
  job:    строки → проходы (одна сторона), разгон overscan, постановка и проверка стола по РАМКЕ, F → S с потолком
  backends/gcode: G21 G90 M4 F; на строку: M5 G0 к началу разгона → G1 X… S0 / S<s> → разгон; M5
```

**Калибровка:** `gerber2ldi pattern bars|dose|square|grid --profile P` → синтетический `Layer` из `Shape` → тот же
`job` (калибровка, компенсация, стол, S) → `.nc`; у полоски дозы ещё и полосы мощности `PowerBand` → `Dose`.

`grid` — не замер, а тест покрытия: прямоугольник, заполненный линиями, чтобы судить проявку по всей площади.

**Будущее (не в шаге 1):** `machine/` (дверь, отправка, снимок состояния) → камера → совмещение по отверстиям
(аффинная подгонка, поворот — на входе до растеризации) → `gui/`.

## 2.3. Словарь

| термин | значение |
|---|---|
| строка (`ScanRow`) | один проезд лазера по оси сканирования на высоте `y`; список отрезков «лазер вкл» |
| отрезок | `(x0, x1)` в мм, `x0 < x1`; в строке — отсортированы, не касаются |
| общая середина | слой `scan/`: всё после входа работает над строками отрезков |
| шаг строки | `row_step_um` — шаг по оси, поперёк сканирования (у китайского станка — по балке); обязан быть целым числом шагов мотора по Y |
| шаг мотора | `steps_per_mm_x/y` (`$100/$101`) — сколько микрошагов контроллер считает на миллиметр; свойство СТАНКА, а не скана |
| сетка | шаблон `grid`: линии шириной `--line-mm` через `--gap-mm` по всему прямоугольнику; тест покрытия, не замер |
| полоса разгона | `overscan_mm` — проезд за краем рисунка, чтобы светить на постоянной скорости |
| компенсация пятна | сужение рисунка на радиус пятна (Д §3.4) |
| процесс | `etch-resist` (резист закрывает медь, светим медь) / `plating-resist` (светим промежутки) |
| доля мощности | от оптической мощности модуля; не больше `usable_fraction` |
| перекос | неперпендикулярность осей, `skew_deg` (Д §17) |
| тестовые штрихи | группы линий и промежутков заданных ширин (бывшее «мира»); в шаблоне `bars` — две группы направлений |
| полоса мощности | диапазон y РИСУНКА с одной долей мощности; даёт `S` каждой строке своего диапазона |
| остаток | замер квадрата с `--with-calibration`: масштаб УМНОЖАЕТСЯ на отношение сторон, угол СКЛАДЫВАЕТСЯ с остатком (а не заменяет значения) |
| дверь | единственный путь к устройству (станок, камера) с одним владельцем (З §2) |
| Демон | DeepSeek — исполнитель заданий |
