# docs/map/ — карта проекта Gerber2LDI

По образцу KiCadStamp (`techdocs/map/` там). С 21.10.2026 карта — в `docs/map/`, в git (Денис: «существенное сопровождение к проекту»). Карта — подсказка, а не истина: расходится с кодом — прав код,
а карту поправить.

- **`index.md`** — указатель, СОБРАННЫЙ ИЗ КОДА: модули (строки всего / кода, первая строка docstring, пометка
  `⚠ >800`), публичное API, кто кого импортирует, сторожа `tests/repo/`. Генерируется, руками не правится.
- **`map.md`** — «одно правило — одно место» (хозяин каждого правила), потоки, словарь, где лежат данные.
- **`structures.md`** — что лежит в чём: строки отрезков, задание, профиль станка.
- **`contracts.md`** — сквозные договоры. Читать ДО задания и ДО приёмки — действуют, даже если задание их не
  назвало, и задание обязано назвать те, что задача задевает.

## Перегенерация `index.md`

Linux / macOS:
```sh
.venv/bin/python tools/project_map.py
```
Windows:
```bat
.venv\Scripts\python.exe tools\project_map.py
```

`tools/project_map.py` — копия генератора KiCadStamp (20.10.2026), отличаются только списки пакетов
(`PACKAGES`, `INTERNAL_TOP`, `DIAGNOSTICS_DIR`). Сторожа генератора (`tests/repo/test_project_map.py` в
KiCadStamp) сюда пока не перенесены.

Перед заданием сверь SHA в шапке `index.md` с `git rev-parse HEAD`. Отстал — перегенерируй. После задания,
которое добавило, переименовало или удалило модуль или публичную функцию, — перегенерируй; поменялось правило
или поток — поправь `map.md` в том же заходе.
