# Gerber2LDI

Засветка фоторезиста лазером (LDI) по файлам Gerber: лазер 405 нм засвечивает
резист строка за строкой, включаясь и выключаясь по положению.

Конвейер: геометрия гербера → отрезки «вкл/выкл» по строкам → компенсация
пятна, зеркало, полярность, совмещение → задание для станка (сначала G-code для
прошивок семейства GRBL). Промежуточного растра нет: картинка добавила бы только
дискретизацию и память.

Состояние: ранняя разработка, пользоваться пока нечем.

## Что уже работает

```sh
gerber2ldi info layer.gbr                    # единицы, размер, апертуры, полярность
gerber2ldi raster layer.gbr -o layer.tif    # строки станка + превью в TIFF
gerber2ldi job layer.gbr --profile profiles/china_ldi_grbl.toml \
    --power 0.8 -o layer.nc                 # программа для станка
gerber2ldi preview layer.nc -o layer.png    # что именно станок нарисует
gerber2ldi pattern bars --profile P --power 0.6 -o bars.nc      # пятно и разрешение
gerber2ldi pattern dose --profile P --from 0.02 --to 0.16 --count 6 -o dose.nc
gerber2ldi pattern square --profile P --power 0.6 -o square.nc   # перекос, 150 мм
```

Координаты в программе — рабочие, G54: перед прогоном оператор ставит ноль рабочей
системы в тот же угол стола, который назван в `profile.table.origin`
(`front-left`), иначе проверка «внутри стола» сравнивает числа с системой, которую
никто не выставил. В файле калибровки записана ошибка станка (`scale_x`, `scale_y` —
реальное/заданное, `skew_deg` положителен, когда ось Y наклонена к +X); программа
делит на масштабы и сдвигает строки на `−y·tg(skew)`.

`job` отказывает, а не подгоняет: доля мощности выше потолка `usable_fraction`
из профиля, рисунок, не влезающий на стол вместе с полосой разгона, или маска
без измеренного радиуса пятна (сказать «работаем без компенсации» — явный флаг
`--no-spot-compensation`). Предупреждения — неоткалиброванный станок, период ШИМ
крупнее пятна — идут строками в stderr, без окон.

## Калибровочные шаблоны

`bars` рисует по пять линий в группе, промежуток равен ширине линии, порядок
200, 150, 100, 80, 60, 50 мкм: сначала горизонтальные (разрешение по Y — пятно и шаг
строки), затем вертикальные (разрешение по X — края пятна и штрихи ШИМ). `dose`
кладёт прямоугольники друг над другом по Y, снизу вверх мощность растёт; уровни —
явный список `--powers` или геометрический ряд (`--from/--to/--count`, потому что
доза действует мультипликативно), а соответствие «прямоугольник → y, мощность, S»
печатается и пишется в шапку `.nc`. Уровень выше `usable_fraction` — отказ, не
подрезка.

`square` рисует контур L×L. Диагонали меряются штангенциркулем: `d1` — от переднего
левого угла к заднему правому, `d2` — от переднего правого к заднему левому, и
`skew_deg = (d1 - d2) / (√2 · L)`, где L — ИЗМЕРЕННАЯ сторона, не номинальная. Без
`--with-calibration` квадрат игнорирует масштабы и перекос из профиля: замер
абсолютный и пишется в файл калибровки как есть. С флагом квадрат рисуется через
текущую калибровку, и тогда замер — ОСТАТОК: его ПРИБАВЛЯЮТ к текущим значениям, а
не заменяют их (команда говорит это в stdout).

Все три идут без компенсации пятна, если не задан `--with-compensation`: штрихи —
то, по чему пятно и МЕРЯЮТ, поэтому требовать замер заранее было бы замкнутым
кругом. Шаблон — обычная геометрия (полигоны `Shape`) и проходит тот же `job`, что и
слой гербера, второго пути нет: поэтому полоса строк и может нести свою мощность.
Мощность по строкам запрещена вместе с компенсацией — она добавляет и убирает строки.

Геометрия берётся прямо из гербера — промежуточного растра в конвейере нет, а
TIFF нужен только глазам. Везде миллиметры, по X ничего не дискретизируется
(это решает станок), строка снимается по центру проезда: `y0 + (i + 0.5) · step_y`.

Известные особенности библиотек, которые обходим: `Rectangle.to_arc_poly()` в
gerbonara возвращает рамку повёрнутого прямоугольника, поэтому прямоугольники
строятся по углам; pygerber не поворачивает макрос-примитив 5, поэтому
повёрнутые многоугольные пады сверяются с аналитикой, а не с ним.
