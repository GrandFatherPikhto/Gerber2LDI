# Gerber2LDI

Засветка фоторезиста лазером (LDI) по файлам Gerber: лазер 405 нм засвечивает резист
строка за строкой, включаясь и выключаясь по положению.

Конвейер: геометрия гербера → отрезки «вкл/выкл» по строкам → компенсация пятна,
зеркало, полярность, калибровка → задание для станка (G-code для прошивок семейства
GRBL). Промежуточного растра нет: картинка добавила бы только дискретизацию и память.

Состояние: ранняя разработка. Программа собирает и проверяет задание и пишет файл;
**на станке задание ещё не выполнялось** — всё, что так помечено ниже, не проверено.

## Что уже работает

```sh
gerber2ldi info layer.gbr                     # единицы, размер, апертуры, полярность
gerber2ldi raster layer.gbr -o layer.tif      # строки + превью в TIFF для глаз
gerber2ldi job layer.gbr --profile profiles/china_ldi_grbl.toml \
    --power 0.6 -o layer.nc                   # программа для станка
gerber2ldi preview layer.nc -o layer.png      # что именно станок нарисует
gerber2ldi pattern bars   --profile P --power 0.6 -o bars.nc
gerber2ldi pattern dose   --profile P --from 0.02 --to 0.16 --count 6 -o dose.nc
gerber2ldi pattern square --profile P --power 0.6 -o square.nc
```

## Чего эта программа НЕ делает

* **Не выгружает герберы из KiCad.** Для этого есть командная строка самого KiCad
  (`kicad-cli pcb export gerbers`, `kicad-cli pcb export drill`); проект читает файлы,
  а не делает их.
* **Не выставляет рабочий ноль.** G54 — дело оператора: подвести головку к углу стола,
  названному в `profile.table.origin`, и послать `G10 L20 P1 X0 Y0` (или нажать
  «ноль» в программе-отправителе).
* **Не разговаривает со станком.** Ни порта, ни потоковой отправки: она пишет файл.
  Отправлять — UGS, LaserGRBL или Candle.
* **Не калибрует себя.** Три шаблона засвечиваются и меряются вами, штангенциркулем и
  микроскопом; числа пишутся в файл калибровки.
* **Не ставит диагноз процессу.** Она отказывает там, где может доказать ошибку;
  остальное — таблица симптомов в конце.
* **Не делает процесс безопасным.** Экран, очки и кнопка стоп — на вашей стороне стола.

## Работа со станком

### 1. Герберы из KiCad

Выгрузить медь, контур платы и сверловку:

```sh
kicad-cli pcb export gerbers board.kicad_pcb -o gerbers/
kicad-cli pcb export drill board.kicad_pcb -o gerbers/
```

Дальше посмотреть, что пришло: `gerber2ldi info` печатает единицы, размер, число
апертур и фигур и есть ли светлая полярность (`%LPC*%`). Размер, не совпавший с
платой, — первое, что надо поймать.

*В этом проекте не прогонялось: обе строки `kicad-cli` — по документации KiCad, а не
из запуска здесь.*

### 2. Профиль и калибровка

`profiles/china_ldi_grbl.toml` — отправная точка: скопировать и поменять размер стола,
`scan.row_step_um`, `scan.speed_mm_s`, `scan.overscan_mm`, `laser.s_max`,
`laser.usable_fraction`. Профиль описывает ТИП станка и лежит в git.

Измеренная ошибка вашего экземпляра лежит рядом, в `profiles/<имя>.calibration.toml`:

```toml
[calibration]
scale_x = 1.002      # реальное / заданное
scale_y = 0.998
skew_deg = 0.1       # > 0: реальная ось Y наклонена к +X
spot_radius_um = 150 # измерено шаблоном bars
measured = 2026-10-21
```

Нет файла калибровки — предупреждение, приняты нейтральные значения (масштаб 1,
перекос 0). Нет замера пятна — **отказ** строить компенсацию; `--no-spot-compensation`
говорит вслух, что вы согласны на линию шире нарисованной.

### 3. Собрать задание

```sh
gerber2ldi job F_Cu.gbr --profile profiles/china_ldi_grbl.toml \
    --power 0.6 -o top.nc
gerber2ldi job B_Cu.gbr --profile profiles/china_ldi_grbl.toml \
    --power 0.6 --side bottom --process plating-resist --place 20,30 -o bottom.nc
```

* `--side bottom` зеркалит рисунок: резист засвечивается с другой стороны.
* `--process` — для чего резист: `etch-resist` светит МЕДЬ (резист остаётся там, где
  медь), `plating-resist` светит ПРОМЕЖУТКИ.
* `--power` — доля от модуля; выше `usable_fraction` — отказ, а не обрезка.
* `--place X,Y` ставит начало полосы разгона в эту точку стола. KiCad пишет
  отрицательные Y; программа ставит рисунок на стол и проверяет весь проход вместе с
  разгоном против стола. Без `--place` рисунок идёт в начало координат.

### 4. Проверить перед засветкой

```sh
gerber2ldi preview top.nc -o top.png
```

На что смотреть: верх картинки — большее Y (вид сверху, как в GerbView); нижняя
сторона выходит зеркальной; медь против промежутков соответствует `--process`;
пропорции совпадают с платой. Превью можно построить и из гербера с профилем
(`preview layer.gbr --profile … -o layer.png`) — это показывает задание до файла.

### 5. Станок, один раз

Две настройки GRBL решают, что значат числа в файле; обе названы в его шапке, так что
файл никогда не двусмыслен:

* **`$32=1` — лазерный режим.** `M4`/`M5` переключают луч и без него. Но БЕЗ лазерного
  режима GRBL **останавливается на каждой смене `S`**: головка тормозит, луч горит,
  пока она ждёт, и каждое место смены мощности пересвечено. С `$32=1` мощность меняется
  на ходу.
* **`$30` = `laser.s_max` профиля** (1000 в китайском профиле). `S` — доля ИМЕННО от
  этого числа: меньший `$30` в прошивке делает `S600` больше задуманного, больший —
  меньше.

Проверить командой `$$`, выставить: `$32=1`, `$30=1000`.

*На станке не проверялось: шапку стережёт тест, а поведение контроллера с неверным
`$30` — дело контроллера.*

### 6. Перед каждым запуском

Рабочий ноль G54 — в углу стола, который назван в `profile.table.origin` (`front-left`).
Подвести головку над углом и в консоли отправителя:

```
G10 L20 P1 X0 Y0
```

(или кнопка «выставить ноль» в отправителе). Числа в программе — рабочие координаты;
проверка «внутри стола» сравнивает их с системой, которая должна существовать. Дальше:
плата ровно на вакуумном столе, фокус выставлен, первый проход на малой мощности.

### 7. Отправка

Готовый файл `.nc`, отправленный программой для GRBL: **UGS** (Universal Gcode Sender),
**LaserGRBL** или **Candle**. Что важно:

* потоковая отправка с «character counting» (отправитель держит несколько строк
  впереди), а не построчная с ожиданием после каждой;
* никаких преобразований в отправителе — ни масштаба, ни сдвига, ни «оптимизации», ни
  переупорядочивания: это файл координат, а не картинка.

*На станке не проверялось: ни один из трёх отправителей с этой программой ещё не
работал. Сам `gerber2ldi` порт не открывает.*

### 8. Безопасность

Лазер 405 нм — видимый фиолетовый, и глаз фокусирует его на сетчатке.

* **Экран** из оранжевого акрила на 405 нм вокруг рабочей зоны или **очки** с указанной
  оптической плотностью на 405 нм (OD4+). Выбирать по МАРКИРОВКЕ (диапазон должен
  включать 405 нм, а OD — быть указан), никогда по цвету линзы.
* **Обычные очки не защищают**: стекло пропускает 405 нм; «защитные очки» из
  хозмага про эту длину волны ничего не говорят.
* Первые проходы — на малой мощности; пробная засветка на обрезке, а не на плате.
* **Останавливать** кнопкой станка или сбросом в отправителе (`Ctrl-X` / reset), а не
  закрытием окна программы.
* Не оставлять лазер включённым, пока головка не движется.

*Здесь не проверялось: выбор экрана и очков — дело оператора; программа их не видит и
не управляет ими.*

Собственные сторожа программы скромные и настоящие: потолок мощности — отказ, и проход
вместе с разгоном обязан влезть на стол. Всё, что может погасить луч — концевики,
аварийная кнопка, сторожевой таймер — в прошивке и на станке: окно на ПК — обещание,
которое некому сдержать, пока движение уже началось.

### 9. Калибровка по шагам

1. `pattern bars --profile … --power 0.6 -o bars.nc` — засветить и проявить. Самая узкая
   группа, у которой выжили и линии, и промежутки, даёт пятно: `spot_radius_um` ≈
   половина наименьшей разрешившейся ширины (оценка сверху; компенсация сужает рисунок
   на этот радиус).
2. `pattern dose --profile … --from 0.02 --to 0.16 --count 6 -o dose.nc` — засветить и
   проявить; прямоугольник, который выглядит правильно, даёт `--power` для плат.
   Соответствие «прямоугольник, снизу вверх → y, мощность, S» печатается и пишется в
   шапку.
3. `pattern square --profile … --power 0.6 -o square.nc` — засветить, затем измерить
   штангенциркулем обе диагонали и обе стороны. `d1` — от переднего левого угла к
   заднему правому, `d2` — от переднего правого к заднему левому, и
   `theta = (d1 - d2) / (√2 · L)`, где `L` ИЗМЕРЕНА, а не номинальная. Команда печатает
   формулы с уже подставленными текущими числами:
   `scale_x = measured X side / 150.000 mm`, `skew_deg = theta`.
4. Записать их в `profiles/<имя>.calibration.toml` с `measured = YYYY-MM-DD`.
5. Проверить: `pattern square … --with-calibration` рисует квадрат ЧЕРЕЗ калибровку и
   печатает `scale_x_new = 1.002000 * (measured X side / 150.000 mm)`,
   `skew_new = 0.1000 deg + theta`. Масштаб — коэффициент, поэтому умножается; перекос —
   угол, поэтому складывается.

Квадрат игнорирует масштабы и перекос профиля, если не задан `--with-calibration`: он
их МЕРЯЕТ, а измерение величины через саму себя даёт остаток, а не величину. Все три
шаблона идут без компенсации пятна, если не задан `--with-compensation`: штрихи — то,
по чему пятно и МЕРЯЮТ.

### 10. Если что-то не так

| симптом | вероятная причина | что делать |
|---|---|---|
| края и места смены мощности пересвечены, «ступеньки» вдоль линии | нет лазерного режима: GRBL стоит на каждой смене `S` | `$32=1` |
| мощность почти не влияет, всё слабо или всё передержано | `$30` ≠ `laser.s_max` | выставить `$30` по профилю |
| засветилась не та сторона | `--side` | `top` для стороны, которую рисуете первой, `bottom` для зеркальной |
| рисунок на краю стола или за ним | не выставлен рабочий ноль или нет `--place` | `G10 L20 P1 X0 Y0` в углу `front-left`, либо `--place X,Y` |
| дорожки толще нарисованных, промежутки слиплись | нет компенсации или неверный `spot_radius_um` | перемерить `bars`, вписать радиус |
| стороны не совпадают | неверный знак `skew_deg` или масштаб | `pattern square --with-calibration`, взять напечатанные формулы |
| не засветилось вообще ничего | старый файл без `M4` после `G0` | пересобрать; сверить с образцом ниже |

Правильный проход выглядит так (первые строки любого `.nc`):

```
M5
G0 X0 Y0
M4 S0
G1 X5.09 S0
G1 X80.821 S600
```

## Как читать шапку .nc

```
; requires GRBL laser mode $32=1
; work coordinates G54: the operator sets the work zero at the table corner named by profile.table.origin (front-left)
; spot compensation: off
; calibration in force: scale_x=1.002000 scale_y=0.998000 skew=0.1000 deg
; GRBL: $32=1 (laser mode), $30=1000 (max spindle speed: the power word is a fraction of it)
```

* первые две строки говорят, на что рассчитан файл: лазерный режим и рабочий ноль в
  названном углу;
* `spot compensation` — сужен ли рисунок на радиус пятна;
* `calibration in force` — какие масштаб и перекос РЕАЛЬНО применены (это НЕ значения
  из файла, если шаблон нарочно рисовал без них);
* строка `GRBL` повторяет обе настройки с `s_max` профиля: файл несёт систему, в
  которой читаются его `S`;
* шаблон добавляет свои строки: что рисует, как мерить, применена ли калибровка и
  формулы для файла калибровки.

## Координаты и отказы

Координаты в программе — рабочие координаты G54: проверка «внутри стола» верна ровно
настолько, насколько верен выставленный оператором ноль. В файле калибровки записана
ошибка станка (`scale_x`, `scale_y` — реальное/заданное, `skew_deg` положителен, когда
ось Y наклонена к +X); программа делит на масштабы и сдвигает каждую строку на
`−y·tg(skew)`.

`job` отказывает, а не подгоняет: мощность выше потолка, рисунок, не влезающий на стол
с разгоном, пятно без замера без `--no-spot-compensation`, неизвестное начало координат
стола, ось сканирования не X. Предупреждения — неоткалиброванный станок, период ШИМ
крупнее пятна — строки в stderr, без окон.

Геометрия берётся прямо из гербера — промежуточного растра в конвейере нет, а TIFF
нужен только глазам. Везде миллиметры, по X ничего не дискретизируется (это решает
станок), строка снимается по центру проезда: `y0 + (i + 0.5) · step_y`.

## Известные особенности библиотек, которые обходим

`Rectangle.to_arc_poly()` в gerbonara возвращает рамку повёрнутого прямоугольника,
поэтому прямоугольники строятся по углам; pygerber не поворачивает макрос-примитив 5,
поэтому повёрнутые многоугольные пады сверяются с аналитикой, а не с ним.
